# 바탕화면 뿌시기

macOS 바탕화면과 현재 화면 위에 시각 효과를 덧씌워 마음껏 부수는 장난감 앱이다. 실제 파일, 창, 바탕화면 이미지는 변경하거나 삭제하지 않는다.

## 바로 실행하기

```bash
./scripts/build-app.sh
open "dist/바탕화면뿌시기.app"
```

빌드된 앱은 `dist/바탕화면뿌시기.app`에 생성된다.

## 조작법

- `1`: 망치 — 클릭하거나 드래그하며 화면에 큰 균열과 파편을 만든다.
- `2`: 기관총 — 마우스를 누르고 있으면 연사한다.
- `3`: 화염방사기 — 마우스를 누르고 움직여 화면을 그을린다.
- `4`: 시한폭탄 — 원하는 곳에 설치하면 잠시 후 화면 전체를 번쩍이며 폭발한다.
- `5`: 전기톱 — 마우스를 누르고 드래그해 화면을 깊게 절단한다.
- `6`: 번개포 — 클릭하거나 누른 채 움직여 갈라지는 번개를 내리꽂는다.
- `R` 또는 `C`: 모든 흔적을 지운다.
- 우클릭: 모든 흔적을 지운다.
- `Esc`: 즉시 앱을 종료한다.

상단 조작 패널은 드래그해 옮길 수 있다. 여러 모니터와 macOS 전체 화면 Space에서도 작동한다.

## 개발

```bash
swift build
```

Swift Package Manager와 AppKit으로만 구현했으며 외부 패키지는 사용하지 않는다. macOS 15 이상에서 실행된다.
